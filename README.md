# CursorFade（鼠标淡化）

> Fade the animated character of your cursor skin while typing — keep the pointer, drop the occlusion.
> 打字/拼音选字时自动只淡化光标皮肤里的**角色动图**部分，指针本体保持清晰，不再遮挡输入法候选文字。

## 特性

- **角色/指针分离淡化**：逐帧差异自动分离皮肤中的"角色动图"与"指针本体"，只淡化角色（任意 `.ani/.cur` 动态皮肤自动适配，无需配置）
- **触发条件**（三路判定）：
  1. 输入法候选窗出现在指针附近（支持手心/搜狗系/QQ/百度/Rime 等按类名与进程名识别的输入法）
  2. 指针在输入框内（文本光标）且正在打字
  3. 指针被候选窗盖住时同样生效
- **输入框上下文门**：鼠标停在非文本区域且未打字时不会误淡化
- **强度可调**：0%（完全隐藏角色）～ 50%，可选平滑渐变过渡
- **例外应用**：临时例外（退出目标程序即恢复）/ 永久例外（写入配置重启仍有效）
- **单文件绿色程序**：无安装、无网络行为、无遥测

## 运行要求

- Windows 10 / 11 x64
- 双击 `CursorFade.exe` 即可运行（自包含，无需安装 .NET 运行时）
- 建议勾选托盘菜单中的"开机自启"

## 使用

程序启动后常驻系统托盘（蓝底 I 形图标，可能收纳在 `^` 溢出区），右键打开菜单：

| 菜单项 | 作用 |
|---|---|
| 启用遮挡淡化 | 总开关 |
| 淡出强度 | 0%（完全隐藏角色）/ 15% ～ 50% |
| 切换时渐变过渡 | 淡入淡出改为多档平滑渐变（默认关闭=瞬切） |
| 输入且指针在输入框内时淡出 | 打字路径开关 |
| 临时例外（退出该程序即恢复） | 当前前台应用加入会话级例外，目标程序退出自动清除 |
| 永久例外（重启仍生效） | 写入配置文件，重启后仍保留 |
| 测试淡出效果（2 秒） | 手动预览 |
| 立即还原光标（光标异常时优先尝试） | 强制复位当前光标状态 |
| 查看日志 | 打开运行日志 |
| 重启本程序（状态异常时用） | 一键自恢复 |
| 退出 | 退出并还原光标 |

配置、日志、淡化缓存位于：
`%APPDATA%\CursorFade\` 与 `%LOCALAPPDATA%\CursorFade\`

## 安全说明（致杀毒软件与用户）

本程序为纯本地工具，**无任何网络访问、无遥测、无数据收集**。它仅通过公开的 Windows API：
替换系统光标（`SetSystemCursor`）、监听全局键盘以判断"正在打字"（`SetWindowsHookEx`）、读取窗口列表判断输入法候选窗。开机自启仅为启动自身。

仓库中 `tools/simulate-ime.ps1` 是**开发期测试脚本**：它会把 `powershell.exe` 复制为
`weaselserver.exe` 以模拟一个输入法候选窗，用于验证识别逻辑——这是本仓库中唯一会
"复制并重命名系统程序"的行为，**仅存在于 tools 目录、非程序运行所需**，杀软若对它报警属预期，
普通使用者无需运行它。

## 已知边界

1. **自绘光标的程序**（部分全屏游戏、少数软件）绕过系统光标，淡化对其无效
2. 任务管理器强制结束后，光标会停留在淡化状态，**下次启动自动修复**
3. **微软拼音不适配**：其候选窗不是独立窗口、IMM 组合态在本机也不可读——打字时仅由
   "文本光标+打字"路径覆盖（停顿超过 1.2 秒会恢复，属已知行为）
4. 启动后约 1 秒的缓存预热期内，首次打字不淡化（防止生成卡顿，设计如此）
5. 多显示器按"窗口所在屏幕"判定全屏排除；识别到的输入法窗口类名会自动学习（见日志可手动清理 `%APPDATA%\CursorFade\config.json` 中 `LearnedClasses`）

## 从源码构建

```powershell
dotnet publish .CursorFade.csproj -c Release -p:PublishSingleFile=true
# 产物直接输出到桌面 CursorFade\ 目录（见 csproj 的 PublishDir）
```

自检：`CursorFade.exe --selftest`（生成淡化副本、校验可加载性、临时切换并还原，退出码 0=通过）
